离线双语字幕编辑器 · 使用说明

这是一个下载后可断网使用的字幕编辑工具，适合对照本地音视频听校已有字幕、修改中英文台词和校准时间。首次打开是空白工程，不含任何真实视频或真实字幕。包内的“练习字幕.srt”只有 3 条虚构台词，可用来试操作。

一、打开工具
1. 下载 ZIP，先完整解压到电脑上的一个文件夹。
2. 双击包内的 HTML 文件，用浏览器打开。建议使用电脑端 Chrome 或 Edge。
3. Mac 和 Windows 都可使用。若双击后用其他程序打开，右键 HTML 文件，选择“打开方式”，再选 Chrome 或 Edge。
4. 打开和编辑无需联网、登录、邀请码或组长密钥。此离线版不提供字幕组联网协作。

二、开始听校
1. 点击“载入音视频”，选择电脑上的视频或音频文件。
2. 点击“导入 SRT / ASS / JSON”，选择已有字幕或保存过的工程。也可先导入包内的练习字幕；它并不对应真实片源。
3. 对照播放，修改中文字幕、英文字幕、说话者和备注。用“开始 / 结束”或“当前位置设为开始 / 结束”校准时间。
4. 新建字幕可点击“在当前位置新增”；支持拆分、合并、搜索、批量时间偏移和撤销。
5. 本工具不会自动转写音视频，也不会自动 AI 翻译。中英文内容由你导入或填写。

三、保存与继续编辑
关闭前请点击“保存工程 JSON”，把文件存到自己找得到的位置。
下次打开工具，导入这个 JSON，再重新选择对应的音视频，即可继续编辑。
JSON 保存完整字幕工程、角色颜色、备注和样式，不包含音视频文件。
浏览器暂存只属于当前电脑和浏览器，不会随 HTML 或 ZIP 一起转移；移动 HTML、更换浏览器、清除浏览器数据或使用隐私模式后，暂存可能无法恢复。请以自己保存的 JSON 文件作为备份。
将工程发给其他人时，可分享 JSON；若对方需要听校，再单独提供对应片源。

四、导出
“导出 SRT”：保存字幕文字和时间，适合交给其他字幕或视频软件使用。
“导出 ASS”：保存字幕文字、时间和本工具的双语样式。
“保存工程 JSON”：用于备份和继续修改。

“导出带字幕视频”有两种方式：
1. 浏览器录制片段：先载入浏览器能播放的本地视频。每次最多 5 分钟，最高 720p / 30 帧，按正常播放速度生成。导出时保持页面在前台。浏览器支持时输出 MP4，否则可能输出 WebM；音频文件不能直接导成视频。
2. 本机 FFmpeg 导出包：先下载并解压视频导出包，再运行包内对应系统的脚本，选择原视频生成 MP4。这不是点击按钮就得到成品视频；需要电脑已安装带 ASS 滤镜的 FFmpeg 和可用的中文字体。工具不附带 FFmpeg，也不会自动安装。未准备好 FFmpeg 时，可先导出字幕文件。
本离线版不包含网页版的“直接保存 MP4”编码功能。

五、常见情况
视频打不开：换一个当前浏览器支持的本地视频格式再试。
暂存提示失败：立即保存 JSON，编辑和字幕导出仍可使用。
字幕字体不同：预览和视频导出使用电脑上可用的字体；换电脑后可能使用替代字体。
需要移动工具：带上 HTML 和已保存的工程 JSON，音视频文件另外保留。
